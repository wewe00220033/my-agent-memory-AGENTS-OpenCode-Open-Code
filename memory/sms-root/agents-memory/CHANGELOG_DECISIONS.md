## 📌 دعم تدفق الأدوات (Streaming Tools & SSE Tool Calls) في الـ Gateway
- **المشكلة اللي اتحلت:**
  - ظهور خطأ `400: "stream": true with "tools" is not supported yet; set stream=false and read tool_calls from the JSON response` في DeepSeek Harness لأن بيئة الوكلاء ترسل دائماً `stream: true` مع تعريفات الأدوات `tools: [...]`.
- **الكود أو الملف اللي اتعدّل:**
  - `gateway/openai_compat.py`: إزالة الحظر القاطع لـ `stream + tools`، وتحديث دالة `sse_stream_chunks` لإرسال كروت الأدوات المكتملة `delta.tool_calls` متضمنة الـ `index` المعياري وفق مواصفات OpenAI SSE.
  - `tests/test_openai_compat.py`: تحديث اختبار الوحدة لضمان قبول تدفق الأدوات بنجاح.
- **الدروس المستفاد لتجنب نفس الخطأ مستقبلاً:**
  - بيئات تشغيل الوكلاء (Agent Runtimes مثل Harness و OpenCode) ترسل الأدوات تلقائياً في كل دورة للموديل مع تفعيل البث المباشر `stream: true`، لذا يجب أن تدعم طبقة الـ Compat الـ streaming مع الـ tools بدون أي استثناءات.
- **أي Risk أو Side Effect محتمل:**
  - تم إجراء كافة اختبارات التوافق والكتالوج بنجاح 100% وبدون أي آثار جانبية.
