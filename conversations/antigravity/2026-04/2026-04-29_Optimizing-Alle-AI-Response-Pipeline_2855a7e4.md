القدرة على التفكير: ده أذكى وأكبر موديل فيهم. ده اللي "بيفكر" صح وبيحلل الكلام حتة حتة قبل ما يرد.

2. موديل Instant (الطلقة)
السرعة: ده بقى بتاع "أسرع رد". متصمم عشان يرد في أجزاء من الثانية. لو بتدور على سرعة خيالية، ده هيكسب.

بس قبل ما أديك الكود السحري، لازم أكون صريح معاك جداً وأحطك في أرض الواقع عشان متضيعش وقتك:
الـ API ده محمي بنظامين تقال جداً:

Cloudflare: وده اللي بيعمل الكوكيز زي __cf_bm.

Sentinel (Play Integrity): وده بياخد توكن من "جوجل بلاي" نفسه عشان يتأكد إن الطلب جاي من تليفون أندرويد حقيقي مش سكريبت بايثون. التوكن ده اسمه play_integrity_token، وده مستحيل البايثون يولده من نفسه أوتوماتيك لأن ده نظام تشفير مقفول بتاع جوجل.

الحل العملي إيه؟ أنا هكتبلك الكود اللي بيلف أوتوماتيك، وبيجيب الـ chat_requirement_token لوحده، وبيغير الـ device-id والـ session-id والـ message-id في كل رسالة عشان تبان كأنها جهاز جديد تماماً. بس هتحتاج تجيب play_integrity_token وكوكيز صالحة تحطها في المتغيرات فوق عشان الكود يكمل شغل، لحد ما تنتهي صلاحيتهم وتحتاج تجيب غيرهم.

    full_text = ""
    for line in response.iter_lines():
        if not line: continue
        decoded = line.decode('utf-8')

        if decoded.startswith("data: "):
            data_str = decoded[6:]
            if data_str == "[DONE]": break

            try:
                data = json.loads(data_str)
                # النظام الجديد بتاع أندرويد (JSON Patch)
                if isinstance(data, dict):
                    # لو جاب append مباشر
                    if data.get("o") == "append" and data.get("p") == "/message/content/parts/0":
                        chunk = data.get("v", "")
                        print(chunk, end="", flush=True)
                        full_text += chunk

                    # لو جاب patch مجمع في مصفوفة
                    elif data.get("o") == "patch" and isinstance(data.get("v"), list):
