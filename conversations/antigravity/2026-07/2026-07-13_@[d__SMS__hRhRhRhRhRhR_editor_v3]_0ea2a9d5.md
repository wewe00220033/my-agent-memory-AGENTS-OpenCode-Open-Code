### 2️⃣ الحل في المعمارية الجديدة (v2): فصل 3 طبقات 🏗️
فكرة **ChainAgent v2** هي إننا نفصل "طريقة التقسيم الذكي" عن "طريقة إدارة الحسابات والـ APIs". وبقى عندنا 3 طبقات منفصلة بتكلم بعض:

#### 📊 الطبقة 1: SmartOrchestrator (المهندس الكبير)
ملوش دعوة بحسابات ولا ترافيك. بيبص على المشروع بتاعك ويحسب نقاط التعقيد (حجم الملف، عدد الملفات، مستوى الخطورة) ويختار الاستراتيجية الأنسب:
* **Direct:** لو ملف صغير وتعديل بسيط (يبعت علطول).
* **ChunkChain:** لو ملف ضخم (يقسمه أجزاء ويبعتهم ورا بعض).
* **MapReduce:** لو تعديل في كذا ملف مترابطين.

#### ⚡ الطبقة 2: ChainExecutor (المنفذ المحترف)
بياخد الخطة من المهندس ويبدأ ينفذ الخطوات خطوة خطوة:
* بيتحكم في التوازي (يشغل كام خطوة مع بعض).
* بيعمل **Retries** (إعادة محاولة) لو حصل خطأ شبكة.
* فيه **CancellationToken** عشان لو دوست "Cancel" في الواجهة يوقف فوراً وميستهلكش حسابات ع الفاضي.
* بيكتب سجل خطوة بخطوة (JSONL Log) عشان لو النور قطع أو السيرفر هنج، لما يرجع يشتغل **يكمل من آخر نقطة وقف عندها (Resume)** وميعيدش من الأول.

#### 🔌 الطبقة 3: Provider Adapter + ExecutionPolicy (المترجم والمنسق)
دي الطبقة اللي بتكلم الـ APIs الحقيقية.
* **Provider Adapter:** بيوحد المدخلات والمخرجات لكل الموديلات (Use.ai, Genspark, DeepSeek...) فكلهم يبانوا قدام السيستم بنفس الواجهة.
* **ExecutionPolicy (سياسة التشغيل):** بتعرف السيستم الموديل ده بيتعامل إزاي مع الحسابات:
  * لو `Use.ai` ──← يشتغل بوضعية `isolated` (حساب جديد لكل خطوة عشان نتخطى الحدود).
  * لو `Genspark` أو `DeepSeek` ──← يشتغل بوضعية `shared` (نفس المحادثة لكل الخطوات).

---

### 3️⃣ تحسينات قوية تانية في الخطة 🎯
* **Targeted Source Retrieval (القراءة الذكية):** في v1 كان الـ AI في الخطوة الأخيرة بياخد "ملخصات" الأجزاء ويعدل على أساسها فكان بيغلط. في v2، الـ Executor هيروح يقرأ **سطور الكود الفعلية الحقيقية** ويحطها قدام الـ AI عشان التعديل يطلع دقيق 100% وميألفش كود.
* **JSON Guard (حارس البيانات):** نظام ذكي بيتأكد إن رد الـ AI طالع بصيغة JSON سليمة وخالية من الأخطاء عشان السيرفر يقدر يفهم التعديلات وينفذها تلقائي بدون كراش.

    def get_project_context(self, max_files: int = 15) -> str:
        """بناء سياق المشروع للبرومبت مع قراءة مجلد الروت تلقائياً وتحديد سقف الحجم"""
        scan = self.scan_project(max_files)
        parts = [
            f"مسار المشروع: {scan['root']}",
            f"عدد الملفات: {scan['total_files']}",
            f"الحجم الإجمالي: {scan['total_size_kb']} KB",
            "",
            "بنية الملفات:",
        ]
        for f in scan["files"]:
            parts.append(f"  - {f['path']} ({f['lines']} سطر)")

        # ─── حقن مجلد الروت تلقائياً (Antigravity Context Sync) ───
        root_dir = self.root / "Root"
        if root_dir.exists() and root_dir.is_dir():
            parts.append("\n⚠️ [معلومات الذاكرة وسياق القرارات الحتمي من مجلد الروت - Root Context]:")
            important_files = ["README.md", "memory.md", "decisions.md", "tasks.md", "ai_state.json"]
            MAX_CHARS = 3000

            for fname in important_files:
                file_path = root_dir / fname
                if file_path.exists() and file_path.is_file():
                    try:
                        content = file_path.read_text(encoding="utf-8").strip()
                        if len(content) > MAX_CHARS:
                            content = content[:MAX_CHARS] + "\n\n_[مقتطع لتوفير المساحة - truncated...]_"
                        parts.append(f"\n📄 [ملف Root/{fname}]:")
                        parts.append(content)
                    except Exception:
                        pass
        return "\n".join(parts)
    ```

    def get_project_context(self, max_files: int = 15) -> str:
        """بناء سياق المشروع للبرومبت مع قراءة كافة ملفات الروت بسقف إجمالي 150 ألف حرف"""
        scan = self.scan_project(max_files)
        parts = [
            f"مسار المشروع: {scan['root']}",
            f"عدد الملفات: {scan['total_files']}",
            f"الحجم الإجمالي: {scan['total_size_kb']} KB",
            "",
            "بنية الملفات:",
        ]
        for f in scan["files"]:
            parts.append(f"  - {f['path']} ({f['lines']} سطر)")

        # ─── حقن مجلد الروت تلقائياً (Antigravity Dynamic Context Sync) ───
        root_dir = self.root / "Root"
        if root_dir.exists() and root_dir.is_dir():
            parts.append("\n⚠️ [معلومات الذاكرة وسياق القرارات الحتمي من مجلد الروت - Root Context]:")

            MAX_TOTAL_CHARS = 150_000
            total_chars = 0

            # مسح كل الملفات النصية في المجلد
            for file_path in root_dir.iterdir():
                if file_path.is_file() and file_path.suffix.lower() in ['.md', '.json', '.txt']:
                    try:
                        content = file_path.read_text(encoding="utf-8").strip()
                        if not content:
                            continue

                        # فحص السقف الإجمالي المتبقي للـ AI
                        if total_chars >= MAX_TOTAL_CHARS:
                            parts.append(f"\n⚠️ [تنبيه: تم الوصول للحد الأقصى للسياق {MAX_TOTAL_CHARS} حرف، تم تجاهل باقي الملفات]")
                            break

                        if total_chars + len(content) > MAX_TOTAL_CHARS:
                            remaining = MAX_TOTAL_CHARS - total_chars
                            content = content[:remaining] + "\n\n_[مقتطع لتوفير المساحة - truncated...]_"
                            parts.append(f"\n📄 [ملف Root/{file_path.name} (مقتطع جزئياً)]:")
                            parts.append(content)
                            total_chars = MAX_TOTAL_CHARS
                            break
                        else:
                            parts.append(f"\n📄 [ملف Root/{file_path.name}]:")
                            parts.append(content)
                            total_chars += len(content)
                    except Exception:
                        pass
        return "\n".join(parts)
    ```
