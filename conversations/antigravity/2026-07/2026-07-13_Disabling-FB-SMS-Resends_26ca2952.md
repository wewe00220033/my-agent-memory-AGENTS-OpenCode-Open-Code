### 🔍 الأسئلة والقواعد المفلترة اللي هنضيفها في المشروع:

#### 1. منع حرق الحسابات والتوكنز (Anti-Token Bloat Rules):
* **قاعدة عدم التخمين أو القراءة العمياء:** بنقول للـ AI: *"ممنوع تطلب قراءة أي ملفات مفيش حاجة تطلبها في سياق العميل الحالي"*.
* **قاعدة الملفات الضخمة (الجراحة البرمجية):** لو العميل شغال على ملف كبير جداً (أكتر من 1000 سطر)، الـ AI لازم يسأل الأول سؤال فلترة:
  * *"أنا شايف إن ملف `X` كبير جداً، هل نركز على الدالة `Y` فقط لتوفير التوكنز ومنع حرق الحسابات؟"*

#### 2. تحويل الخيارات الذكية (`[OPTIONS]`) لخيارات مفلترة ومخصصة للمشروع:
بدل ما الـ AI يقترح اقتراحات مضحكة لسكريبتات الباك-إند (زي "أضف تصميم متجاوب Responsive" أو "Dark Mode")، أجبرناه يقترح خيارات تناسب طبيعة المشروع النشط:
* **إذا كان المشروع سكريبت أتمتة أو باك-إند (زي سكريبتات الفيسبوك والـ SMS):**
  الـ AI مجبر يقترح خيارات زي:
  1. `[1] اختبار خط سير تبديل الأرقام (Number Swap)`
  2. `[2] التحقق من صلاحية الكوكيز (Cookies Status)`
  3. `[3] تتبع مهلة انتظار كود التحقق (OTP Timeout)`
  4. `[4] تحليل سجلات استجابة الـ API`

#### 3. حل مشكلة انعكاس الحروف والكلمات الإنجليزية (RTL Formatting Guard):
لأن المتصفح لما بيقرأ عربي مع إنجليزي بيعكس ترتيب الكلمات (زي كلمات `cookies` أو `FastAPI` أو `OTP`)، ألزمنا الـ AI في البرومبت إنه يغلف أي مصطلح إنجليزي داخل علامات تنصيص مائلة (Backticks) زي كدة: `` `cookies` `` أو `` `OTP` ``. ده بيحمي الكود والكلمة من الانعكاس البصري في الشات وبتظهر مرتبة ومن اليمين للشمال بشكل سليم 100%.

### 📄 ملف 2/6: `.github/workflows/auto-push.yml`
> **المكان:** أنشئ فولدر `.github/workflows/` وحط الملف جواه
> **الهدف:** يعمل Auto-Release ويبعت Notification على تليجرام لما يترفع تحديث جديد

```yaml
name: Auto Release & Telegram Notify

on:
  push:
    branches:
      - main
      - master

jobs:
  release-and-notify:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout Code
        uses: actions/checkout@v4
        with:
          fetch-depth: 0

      - name: Get Version from VERSION file
        id: version
        run: |
          if [ -f VERSION ]; then
            VERSION=$(cat VERSION)
          else
            VERSION="3.1.0"
          fi
          echo "version=$VERSION" >> $GITHUB_OUTPUT

      - name: Generate Changelog
        id: changelog
        run: |
          CHANGELOG=$(git log -1 --pretty=format:"%s%n%n%b")
          COMMIT_HASH=$(git rev-parse --short HEAD)
          AUTHOR=$(git log -1 --pretty=format:"%an")
          echo "changelog<<EOF" >> $GITHUB_OUTPUT
          echo "$CHANGELOG" >> $GITHUB_OUTPUT
          echo "EOF" >> $GITHUB_OUTPUT
          echo "hash=$COMMIT_HASH" >> $GITHUB_OUTPUT
          echo "author=$AUTHOR" >> $GITHUB_OUTPUT

      - name: Send Telegram Notification
        run: |
          MESSAGE="🚀 *WebDev AI Editor - تحديث جديد*

          📦 *الإصدار:* \`v${{ steps.version.outputs.version }}\`
          👤 *المطور:* ${{ steps.changelog.outputs.author }}
          🔗 *Commit:* \`${{ steps.changelog.outputs.hash }}\`

          📝 *التغييرات:*
          \`\`\`
          ${{ steps.changelog.outputs.changelog }}
          \`\`\`

          🌐 [عرض على GitHub](https://github.com/${{ github.repository }}/commit/${{ github.sha }})"

          curl -s -X POST "https://api.telegram.org/bot${{ secrets.TELEGRAM_BOT_TOKEN }}/sendMessage" \
            -d chat_id="${{ secrets.TELEGRAM_CHAT_ID }}" \
            -d text="$MESSAGE" \
            -d parse_mode="Markdown" \
            -d disable_web_page_preview="false"
```
