وهذا متسق مع مجلد السكربت.

## الثاني

```python
return p
```

وهذا يعتمد على current working directory، وليس بالضرورة مجلد السكربت.

لذلك الثاني قد لا يجد الملف إذا شُغل من مجلد مختلف.

**الأول أفضل.**
