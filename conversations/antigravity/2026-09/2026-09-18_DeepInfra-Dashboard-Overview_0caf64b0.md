### agent

موقع **[DeepInfra](https://deepinfra.com/dash)** ده عبارة عن **منصة سحابية متخصصة في تشغيل موديلات الذكاء الاصطناعي (AI Model Hosting & Serverless Inference)** 🚀

ببساطة شديدة: هو بديل أرخص بكتير لـ OpenAI و Anthropic، وبيديك إمكانية تشغل أقوى الموديلات المفتوحة المصدر عن طريق **API** سريع جداً.

---

### 🌟 1. الموقع بيعمل إيه بالضبط؟
* **تشغيل موديلات الذكاء الاصطناعي بدون ما تشتري كروت شاشة:** بدل ما تجيب سيرفر غالي، هما مجهزين كروت GPU عملاقة ومشغلين الموديلات، وأنت بتنادي الموديل بطلب API بسيط (Pay-as-you-go).
* **متوافق 100% مع كود OpenAI:** بتغير بس الـ `base_url` لـ `https://api.deepinfra.com/v1/openai` ومفتاحك، والكود يشتغل فوراً بنفس الـ SDK!

---

### 🛠️ 2. إيه اللي موجود في الداشبورد (`/dash`)؟
1. **إدارة الـ API Keys:** بتعمل مفاتيح ربط عشان تستخدمها في سكريبتاتك أو برامجك 🔑.
2. **رصيد الحساب والاستهلاك (Billing & Usage):** بيحاسبك بالـ Token أو بالثانية بدون اشتراك شهري إجباري، والداشبورد بتوضح بالمليم صرفت كام على كل ريكويست 💳.
3. **تصفح الموديلات وأسعارها (Models Directory):** قائمة بكل الموديلات الجاهزة وأسعار المدخلات/المخرجات وسرعتها ⚡.
4. **مراقبة الأداء (Logs & Analytics):** بتشوف كل الـ Requests، الـ Latency، ومعدل النجاح والأخطاء 📊.

---

### 🤖 3. أهم الموديلات اللي بيقدمها:
* **موديلات النصوص والشات (LLMs):**
  * **DeepSeek** (V3, R1, Coder).
  * **Llama** (Llama 3.1 / 3.3).
  * **Qwen** و **Mistral**.
* **تفريغ وتحويل الصوت (Speech-to-Text):**
  * **Whisper** (لتفريغ الفويس نوتس والتسجيلات بدقة وسرعة خيالية وبسعر شبه مجاني).
* **توليد الصور (Image Generation):**
  * **FLUX.1** و **Stable Diffusion XL**.
* **الـ Embeddings:**
  * موديلات الـ Vector لتطبيقات الـ RAG والبحث الدلالي.

---

💡 **الخلاصة:** هو منصة ممتازة وموفرة جداً لو عايز تشغل موديلات نصوص (زي DeepSeek أو Llama) أو تفرغ صوتيات (زي Whisper) جوه نظامك بدون وجع دماغ السيرفرات الخاصة وبسعر كسر!

خد الرسالة دي جاهزة كوبي-بيست تبعتهاله على طول: 📋👇

> **"موقع DeepInfra ده منصة سحابية بتديك API تشغل بيه أقوى موديلات الذكاء الاصطناعي (زي DeepSeek، Llama، وتفريغ الصوت بـ Whisper) بسرعة عالية وتكلفة رخيصة جداً، وبيركب مكان كود OpenAI بضغطة زرار."** 🚀

ده موقع **Baidu Qianfan (تشيانفان - 千帆)**، المنصة السحابية الرسمية للذكاء الاصطناعي من شركة **Baidu** (اللي هي جوجل الصين) 🇨🇳🤖

تقدر تعتبره المعادل الصيني لـ **Azure AI Studio** أو **Google Vertex AI**.

---

### 🌟 1. الموقع بيعمل إيه؟
* **تشغيل موديلات ERNIE (وينكسين - 文心):** ده الموديل الرائد بتاع بايدو المنافس لـ ChatGPT (زي ERNIE 4.0 و ERNIE Speed).
* **توفير APIs للمطورين:** استدعاء موديلات النصوص، الصور، والـ Embeddings في المواقع والتطبيقات عبر API.
* **تدريب وتخصيص الموديلات (Fine-Tuning):** لو عندك بيانات وعايز تدرّب موديل خاص بشركتك.
* **بناء الـ AI Agents و RAG:** منصة (AppBuilder) لعمل بوتات ذكية وربطها بقواعد بيانات ومستندات.

---

### ⚖️ 2. هل ينفعنا؟ (المميزات والعيوب)
* ✅ **الميزة:** قوي جداً ورخيص، وموديلات زي `ERNIE-Speed` بايدو مخلية استدعاءها مجاني أو بسعر شبه منعدم لمنافسة السوق.
* ⚠️ **العيب:** موجه بنسبة 90% للسوق والشركات الصينية؛ التسجيل وتفعيل الحساب بيحتاج غالباً توثيق هوية صينية (Real-name verification) أو رقم هاتف صيني وطرق دفع محلية، وأغلب الدوكيومنت باللغة الصينية.

ده موقع **[Jina AI](https://jina.ai/)** (وبالتحديد صفحة إدارة الـ API Keys بتاعته) 🧠⚡

منصة **Jina AI** دي من أشهر وأهم المنصات في عالم الـ AI حالياً، ومشهورة جداً بـ 3 خدمات أساسية بيحتاجها أي حد شغال في الأتمتة أو الـ RAG والبحث:

---

### 🌟 أهم حاجات بتعملها Jina AI:

1. **قارئ الويب السحري (Jina Reader API - `r.jina.ai`):**
   * دي أشهر ميزة عندهم! لو حطيت `https://r.jina.ai/` قبل أي لينك موقع في الدنيا، هيسحبلك محتوى الصفحة ويحوله لـ **Markdown نظيف جداً وصافي** خالي من إعلانات الـ HTML وزحمة الـ CSS، وجاهز تديه لأي موديل ذكاء اصطناعي يقراه فوراً 📄✨.

2. **البحث على الإنترنت للموديلات (Jina Search API - `s.jina.ai`):**
   * بتبعتله كويري بحث، يرجعلك نتائج الويب متفلترة وجاهزة ومعدة للاستخدام مع الـ LLMs.

3. **موديلات التضمين وإعادة الترتيب (Embeddings & Reranker):**
   * موديلاتهم في الـ Embeddings والـ Reranking بتدعم نصوص طويلة (حتى 8192 توكن) ومتعددة اللغات، وهي من الأقوى عالمياً في أنظمة الـ RAG وقواعد بيانات الـ Vector (زي Qdrant).

---

### 🔑 صفحة الـ `key-manager` دي لازمتها إيه؟
* أول ما بتسجل في الصفحة دي، بيديك **API Key مجاني** مع رصيد تجريبي محترم (حوالي مليون توكن أو أكتر مجاناً).
* المفتاح ده بتستخدمه عشان تشغل خدمات الـ Reader أو الـ Search أو الـ Embeddings بدون ما يحصلك Rate Limit أو حظر.

---

### 📋 سطرين ملخصين تبعتهم لصاحبك لو حابب: 👇
> **"منصة Jina AI متخصصة في أدوات البحث وقراءة الويب للذكاء الاصطناعي؛ أشهر ميزة عندهم هي تحويل أي صفحة نت لنص نظيف (Markdown) بضغطة واحدة، وتوفير موديلات Embeddings و Reranking قوية جداً لأنظمة الـ RAG، والصفحة دي بتديك API Key برصيد مجاني."** 🚀

**لأ خالص، هما مبيتقارنوش ببعض أصلاً لأن ده تخصص وده تخصص تاني خالص!** 🙅‍♂️💡

عشان تتخيل الفرق بتشبيه بسيط جداً:

* 🧠 **ChatGPT و Gemini:** دول **"المخ والعبقري"** (General LLMs) — دول اللي بتفتح معاهم شات، يفكروا، يحللوا، يكتبوا أكواد، ويكتبوا مقالات ويجاوبوا على أي سؤال في الكون.
* 👓 **Jina AI:** ده **"النظارة أو الأرشيفجي"** اللي بيساعد المخ ده!

---

### يعني إيه؟ 🤔
* أنت مينفعش تفتح Jina AI تتكلم معاه شات وتطلب منه يكتبلك قصة أو ينكت معاك أو يحللك مشكلة نفسية، هو مش معمول لكده.
* **Jina** معمول كـ **"أداة خدمة وبنية تحتية" (Infrastructure Tool)**، بيعمل حاجتين محددين جداً وبارع فيهم:
  1. **قراءة النت (Jina Reader):** لما ChatGPT أو Gemini يحبوا يدخلوا على صفحة ويب ويقروها، كود الـ HTML والـ CSS والإعلانات بيلخبطهم.. Jina هنا يدخل "كنظارة"، ينضف الصفحة ويقدمها لـ ChatGPT على صينية دهب.
  2. **البحث والفرز (Search & Embeddings):** لو عندك 1000 كتاب، Jina هو اللي بيبحث ويرتب ويطلع الصفحة المظبوطة ويسلّمها لـ Gemini عشان يشرحهالك.

---

🎯 **الخلاصة:**
**Jina مش بديل ولا منافس لـ ChatGPT أو Gemini.. بالعكس، هو "مساعد" بيشتغل تحت إيديهم عشان يخليهم يقرأوا الإنترنت والملفات بدقة أعلى!** 🤝🚀

ده توثيق خدمة **Hugging Face Inference Providers** 🌐🤗

ببساطة شديدة: **Hugging Face عملت "سوق مركزي موحد" لتشغيل كل موديلات الذكاء الاصطناعي في العالم من مكان واحد وبحساب واحد!**

---

### 🤔 إيه المشكلة اللي حلتها الخدمة دي؟
زمان (وحتى الآن)، لو عايز تستخدم:
* موديل سريع جداً زي Llama على كروت سريعة كنت بتروح تعمل حساب في **Groq** أو **Cerebras**.
* موديل صور زي FLUX بتروح تعمل حساب في **Fal.ai** أو **Replicate**.
* موديلات تانية بتروح تسجل في **Together AI** أو **Sambanova**.
👈 **النتيجة:** 10 حسابات مختلفة، 10 كروت دفع، و10 مفاتيح API مختلفة تدوخ عشان تديرهم!

---

### 🚀 الحل اللي بتعمله Hugging Face هنا:
1. **مفتاح واحد وحساب واحد (One Key to Rule Them All):**
   * بمفتاح Hugging Face بتاعك (`HF_TOKEN`) وحساب دفع واحد، تقدر تشغل آلاف الموديلات.
2. **بتختار أنت عايز تشغل الموديل فين:**
   * Hugging Face متعاقدة مع كل الشركات الكبيرة دي (Groq, Together, Sambanova, Fal.ai, Hyperbolic.. إلخ).
   * وأنت بتطلب الموديل، تقدر تقوله: *"شغلي الموديل ده عبر سيرفرات Groq عشان عايزه طلقة"* أو *"شغله عبر Together AI"*.. وكل ده بنفس الـ API وبنفس الحساب!
3. **متوافق مع كود OpenAI:**
   * بتناديه بنفس طريقة `openai.chat.completions.create` المعتادة.
