### أولاً: الدليل التقني القاطع (لماذا يحدث هذا؟)

واجهة الشات والـ Agent على اليمين تعمل عبر حزمة مدمجة اسمها **`jetskiAgent`** داخل المسار:
```text
...\resources\app\out\jetskiAgent\main.js
```

عند فحص هذا الملف برمجياً، وجدنا الدوال المسؤولة عن فحص وتمرير الاختصارات وهي:
```javascript
function tFs(e){ let t=e.ctrlKey||e.metaKey; return t && e.keyCode === 86; } // Paste (V)
function rFs(e){ let t=e.ctrlKey||e.metaKey; return t && e.keyCode === 67; } // Copy  (C)
function nFs(e){ let t=e.ctrlKey||e.metaKey; return t && e.keyCode === 88; } // Cut   (X)
function aFs(e){ return (e.ctrlKey||e.metaKey) && [90,89].includes(e.keyCode); } // Undo/Redo (Z/Y)
```

ثم يتم استدعاؤها في دالة مراقبة لوحة المفاتيح:
```javascript
function eFs() {
  ...
  let n = o => {
    if (rFs(o)) { document.execCommand("copy");  o.preventDefault(); return; }
    if (nFs(o)) { document.execCommand("cut");   o.preventDefault(); return; }
    if (tFs(o)) { document.execCommand("paste"); o.preventDefault(); return; }
    ...
    // إذا لم يتحقق أي شرط، يتم إرسال الضغطة للمحرر الرئيسي (IDE):
    t?.onKeyboardEvent(r("keydown", o));
  };
}
```

#### ما الذي يحدث بالضبط بين العربية والإنجليزية؟

1. **الخطأ البرمجي في فحص المفاتيح (`e.keyCode`):**
   * كود البرنامج يفحص رقم الزر المنطقي `e.keyCode` بدلاً من الزر الفيزيائي `e.code`.
   * **في اللغة الإنجليزية:** الزر يرسل أرقام الحروف اللاتينية القياسية (67 لـ C، و86 لـ V، و88 لـ X، و90 لـ Z). وبالتالي الشرط يتحقق فوراً داخل الشات، وتُنفذ الدالة `o.preventDefault()` ويتوقف الحدث هناك.
   * **في اللغة العربية:** في نظام ويندوز، عندما تضغط `Ctrl` مع الحروف العربية (`ش` مكان A، و`ئ` مكان Z، و`ء` مكان X، و`ؤ` مكان C، و`ر` مكان V)، تفشل شروط `keyCode` لأن النظام يعتبر الحرف عربياً وليس إنجليزياً.
2. **تسريب الاختصار إلى نافذة المحرر على اليسار:**
   * عندما يفشل الشرط، لا يتم استدعاء `preventDefault()`، وينتقل الكود إلى السطر الأخير:
     ```javascript
     t?.onKeyboardEvent(r("keydown", o));
     ```
   * يقوم الشات بتمرير الضغطة الفيزيائية (`code: "KeyA"`, `code: "KeyZ"`, ...) مباشرة إلى نافذة المحرر الأساسية في Antigravity.
3. **لماذا يتم التطبيق على الملف المفتوح يساراً؟**
   * محرك VS Code / Antigravity يستقبل أمر `Ctrl + KeyA` قادماً من الشات.
   * أمر **`editor.action.selectAll`** (تحديد الكل) في البرنامج ليس مقيداً بشرط أن تكون داخل المحرر، فيعتبر أنك تريد تحديد محتوى المحرر النشط حالياً (`run_bot.bat` على اليسار)!
   * الأمر نفسه ينطبق على `Ctrl+Z` (يتراجع عن الكود في الملف الأيسر) و `Ctrl+C` و `Ctrl+V`.
