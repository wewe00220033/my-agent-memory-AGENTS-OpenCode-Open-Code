### 2️⃣ التشريح الفني: إيه ميزة كل واحد فيهم عن التاني؟ ⚖️

#### 🟢 الأول: OpenCode (`anomalyco/opencode`)
* **فلسفته:** أداة سريعة وخفيفة جداً لشغل التيرمينال اليومي (CLI / TUI) زي Claude Code.
* **المعمارية:** مبني بـ TypeScript على محرك Vercel AI SDK.
* **مميزاته اللي يتفوق بيها:**
  - ⚡ **السرعة والخفة الفائقة:** تشغيل فوري بدون استهلاك للرامات، واجهة TUI سريعة جداً.
  - 🎯 **تخصيص سهل ومباشر:** ملف إعدادات واحد (`opencode.json`) بتربطه بأي Gateway أو بريدج محلي في ثوانٍ معدودة.
  - 🔄 **نظام الوكلاء المدمجين:** التبديل السلس بـ `Tab` بين وكيل البناء (`build`) ووكيل التخطيط (`plan`) و `@general`.
* **نقاط ضعفه:**
  - ❌ **أدواته محدودة ومباشرة:** محصورة في (`bash`, `edit`, `write`, `read`).
  - ❌ **مفيش عزل (No Sandboxing):** بينفذ الأوامر مباشرة على نظام تشغيلك.
  - ❌ **تعديل الملفات يعتمد على الـ String Replacement:** في الملفات الكبيرة أو المتشابهة في الأسطر ممكن يحصل خطأ في الاستبدال.

---

#### 🔵 الثاني: DeepSeek Harness (`deepseek-ai/deepseek-harness` - المعروف بـ `dsh`)
* **فلسفته:** "نظام تشغيل وكلاء متكامل" (Full Agent Operating System).
* **المعمارية:** مبني على إطار Cordis بفلسفة **"Everything is a Plugin"**.
* **مميزاته اللي يتفوق بيها:**
  - 🏗️ **ترسانة أدوات عملاقة (أكثر من 50 حزمة مدمجة):**
    - دعم أصيل لـ **MCP** (Model Context Protocol).
    - دعم **LSP** (Language Server Protocol) لفهم الكود بالرموز والـ AST مش مجرد نصوص.
    - دعم **Browser-use** و **Computer-use** للتحكم بالمتصفح والشاشة.
    - دعم **Subagents & Teams** (أسراب وكلاء يتعاونون في نفس الوقت).
    - دعم **Docker Sandboxing** لعزل التشغيل عن جهازك الأساسي.
  - 🖥️ **واجهات متعددة:** واجهة ويب كاملة (`dsh web`) وتطبيق ديسكتوب (`dsh desktop`) بجانب الـ CLI.
  - 🧠 **تناغم كامل مع أسلوب DeepSeek:** معالجة أصلية لتاجات التفكير `<think>` وتدفق استدعاء الأدوات.
* **نقاط ضعفه:**
  - ❌ **تقيل ومعقد جداً في البناء:** Monorepo ضخم جداً محتاج وقت وموارد في الـ Build (pnpm, tsx, native bindings).
  - ❌ **ما زال في طور الـ Developer Preview:** تحديثاته سريعة وبتكسر التوافق (Breaking Changes) بشكل مستمر.
  - ❌ **Overkill:** لو عايز تعدل سطر كود أو تسأل سؤال سريع، المنظومة دي بتكون أثقل من اللازم.

#### 🥇 1. Aider (`paul-gauthier/aider`) — الأفضل بلا منازع في تعديل الكود الفعلي
* **ليه أفضل من OpenCode و DeepSeek Harness؟**
  - **خريطة المستودع (Repo Map عبر tree-sitter):** Aider مش بيبعت ملفات كاملة للذكاء الاصطناعي ويهدر توكنز؛ هو بيحلل شجرة الكود (AST) ويبعت بس أسماء الكلاسات والدوال المهمة، فبيفهم علاقات المشروع الضخم بتكلفة توكنز أقل بـ 80%!
  - **وضع المعماري (Architect Mode):** موديل تفكير قوي (زي R1 أو Sonnet) بيصمم الحل ويكتب المنطق، وموديل سريع ورخيص بيكتب الـ Git Patch، وده بيلغي الهبد تماماً.
  - **تكامل Git مدمج وتراجع تلقائي:** كل تعديل بيتعمله `git commit` فوري برسالة واضحة، ولو الـ Tests سقطت بيرجع بالـ Commit فوراً (`Auto-Rollback`).
* **الدليل:** متصدر دائم لاختبارات الـ Code-Editing Benchmark، ومشروع مستقر جداً بآلاف النجوم والمستخدمين المحترفين يومياً.

---

#### 🥈 2. OpenHands (سابقاً OpenDevin — `all-hands-ai/OpenHands`) — الأفضل في الاستقلالية والعزل
* **ليه أفضل؟**
  - **عزل حقيقي عبر Docker (True Sandboxing):** الوكيل بيشتغل جوه Container كامل، يقدر يسطب مكتبات، يقوم قواعد بيانات، يشغل سيرفرات، ومستحيل يلمس أو يمسح أي ملف خارج الحاوية في جهازك بالخطأ.
  - **هندسة معمارية مجربة (CodeAct Architecture):** أثبتت الأبحاث أن كتابة وتنفيذ كود بايثون تفاعلي كأدوات أفضل بمراحل من الـ JSON tool calling التقليدي.
* **الدليل بالأرقام:** متصدر التقييم العالمي الرسمي **SWE-bench Verified** (الذي يختبر قدرة الذكاء الاصطناعي على حل مشاكل حقيقية وـ Bugs في مشاريع برمجية كبرى) بنسب نجاح تتجاوز **65% إلى 72%**، وهو إنجاز لم يصل له OpenCode أو DSH حتى الآن.

### 2️⃣ فحص DeepSeek Harness (`deepseek-ai/deepseek-harness`): ملعب الهاكر الحقيقي

ده بقى مش مجرد أداة، ده **نظام تشغيل كامل للوكلاء (Agent OS)**:

* 🌐 **الـ Gateway والمزودين:**
  - مبني على معمارية محايدة للموديلات (Model-Agnostic)، بتدخل في `packages/llm` وتحدد أي BaseURL أو Proxy محلي.
* 🔌 **دعم الـ MCP Servers:**
  - **مدمج كحزمة أساسية داخل المستودع (`packages/mcp`):** معموله Integration كامل كـ Plugin، وبيقدر يكتشف الأدوات تلقائياً ويحقنها في الـ Context.
* ⚙️ **تعديل الـ Agent Loop (أقوى ميزة فيه):**
  - لأنه مبني على ميتا-فريمورك اسمه **Cordis** بفلسفة *"Everything is a Plugin"*.
  - الـ Loop نفسه مش كود ثابت ومقفول؛ دورة حياة الوكيل، التخطيط (`packages/plan`)، الأهداف (`packages/goal`)، كلها عبارة عن Plugins تقدر تعمل لها Hook أو تستبدلها كلياً ببلوجين خاص بيك!
* 📝 **تعديل الـ System Prompt:**
  - تحكم كامل عبر البلوجينات أو ملفات التهيئة وتعديل كل رسائل التوجيه.
