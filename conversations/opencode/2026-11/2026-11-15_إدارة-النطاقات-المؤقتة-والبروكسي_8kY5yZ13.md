## 📋 أسماء محادثات أوپن كود للمزودين (OpenCode Conversations & Providers)

### نظام الجلسات (Sessions)
- **الجلسة الجذرية (Root Session):** لا تحتوي على `parentID`، تمثل خيط المحادثة الرئيسي، يمكن فتح فروع منها
- **التسمية التلقائية:** `New session - <timestamp>` (مثلاً: `New session - 2026-11-15T10:00:00Z`)
- **إدارة الجلسات عبر CLI:**
  ```bash
  opencode session list
  opencode session list --max-count 20 --format json
  ```

### المزودين المدعومين (75+ Providers)
يستخدم OpenCode **AI SDK** و **Models.dev** لدعم أكثر من 75 مزود نماذج لغوية، منها:
| المزود | الوصف |
|--------|-------|
| **Anthropic (Claude)** | Claude Opus, Sonnet, Haiku |
| **OpenAI (GPT)** | GPT-4, GPT-3.5, وغيرها |
| **Google (Gemini)** | Gemini Flash, Pro |
| **DeepSeek** | نماذج صينية مفتوحة |
| **Ollama** | نماذج محلية |

## 📊 تحليل بيانات Google Sheets (Google Sheets Data Analysis Request)

### التكامل باستخدام MCP Server
يمكن لـ OpenCode الوصول إلى بيانات Google Sheets الحية عبر:

1. **CData Connect AI Remote MCP Server:**
   - يتيح الوصول الآمن لبيانات Google Sheets
   - يدعم الاستعلام المباشر (SQL) على البيانات الحية
   - يربط بين OpenCode وبياناتك في Google Sheets

2. **Composio Google Sheets MCP:**
   - Requires OAuth for authentication
   - URL: `https://connect.composio.dev/mcp`

## 🔒 إدارة النطاقات المؤقتة والبروكسي (Ephemeral Domains & Proxy Management)

### إعدادات البروكسي في OpenCode
```bash
# إعداد متغيرات البيئة للبروكسي
export HTTPS_PROXY=https://proxy.example.com:8080
export HTTP_PROXY=http://proxy.example.com:8080
export NO_PROXY=localhost,127.0.0.1,*.internal.company.com
export NODE_EXTRA_CA_CERTS=[REDACTED:PATH]

opencode service set env HTTPS_PROXY http://proxy.example.com:8080
opencode service start
```

### إعدادات النطاق (Domain Configuration)
- **مفهوم النطاقات المؤقتة**: نطاقات تُنشأ تلقائياً للتعامل مع المهام المؤقتة وتُحذف بعد انتهاء استخدامها
- **خيارات التكوين في `opencode.json`**:
  ```json
  {
    "network": {
      "proxy": {
        "baseURL": "https://proxy.company.com"
      }
    }
  }
  ```
- **CORS domains**: إعداد النطاقات المسموح لها بالوصول عبر `--cors` flag

### حماية إضافية
- عزل الجلسات لمنع تلوث الـ cookies
- حصر الهوست على `127.0.0.1`
- استخدام `Anti-Zombie Watchdog` لربط العمليات بـ Windows Job Object

## 🔍 مراجعة محادثة إدارة النطاقات (Conversation Domain Management Review)

### مبادئ إدارة النطاقات في OpenCode:
1. **عزل النطاقات (Domain Isolation):** كل جلسة تعمل في مجال نطاقها الخاص
2. **التحكم في الوصول (Access Control):** تحديد النطاقات المسموح لها بالتفاعل
3. **سجل المراجعة (Audit Log):** تتبع جميع عمليات الوصول للنطاقات
4. **إنهاء臨時 النطاقات:** إغلاق النطاقات المؤقتة تلقائياً بعد انتهاء المهمة
